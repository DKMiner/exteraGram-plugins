Quiet Notification Group Refresh — experimental exteraGram plugin

This repository is prepared for the exteraGram plugin catalog.

To publish it, upload the contents of this folder to a PUBLIC GitHub repository (keep extera-plugins.json at the repository root), then add that repository URL in exteraGram > Plugins > Add repo.

The plugin has not been run inside exteraGram build 13.1.1 (72379). Treat it as experimental, review the code/security analysis in the app, and disable it immediately if it affects normal notifications.

The .plugin file is Python source code. The ZIP itself is not the plugin file.
